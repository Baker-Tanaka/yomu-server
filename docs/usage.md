# 使い方

- **知識（RAG）**: 解説の下の「📚 知識に登録」を押すと、ローカル LLM がその解説から用語と要点を整理して保存します。
  あとで別の語・英文・数式を解説したり質問したりするとき、意味の近い知識（埋め込みモデルで探す）を最大 3 件 AI に添えます。
  添えたときは解説カードに「📚 参考にした知識」と出ます。⚙ の「知識（RAG）」で一覧を見て、要らないものを消せます
  - 知識を足したり消したりすると、その知識を添える解説は作り直しになります（古い解説は出しません）
  - 市販の教材や講座の文章は登録しないでください（解説から AI が整理したものだけを保存します）
- **数式の解説**: 本文の数式をタップ（クリック）すると式の全体が選ばれ、「解説する」で記号の意味・式の読み解き・本文とのつながりを説明します。
  解説のあとの「続けて質問する」も使えます。複数行の式は、まとめて 1 つの数式として扱います。
  - LLM には元の LaTeX を渡します。英文の中の数式と、段落（文脈）の中の数式も LaTeX（`$…$`）にして渡します
  - 解説・チャットと、選んだ数式の表示では、`$…$` の LaTeX を数式の形に組みます（添字、分数、根号、ハットなど、∑ の上下、
    場合分け、行列）。専用の数式エンジンではなく、画面のフォントと線で組む簡易な組版なので、細かい字体や間隔は本文と違います
    - 文の中の分数は、行が重ならないように `1/N` の形にします。横に長い式は少し縮め、それでも収まらなければ横にスクロールします
    - 対応していない命令は名前をそのまま出します。1 行で出すところ（スマホの小さな表示、履歴、スラッシュリーディング）は、
      `π_θ` のような読める文字にします。「コピー」では元の LaTeX がコピーされます
- **スラッシュリーディング**: 英文の解説の和訳の次に、意味のまとまりごとの英語と直訳を上下に組み、英語の語順のまま左から右へ「／」で区切って並べます
  （LLM の出力を組に読み替えられないときは、区切った英文と直訳の箇条書きをそのまま表示します）
  （「- **チャンク**：直訳」）を出します。区切る位置は、長い主部の後、前置詞句・to 不定詞・分詞・関係詞節・接続詞の前などを目安に LLM が選びます。
  解説カードの下か ⚙ の「スラッシュリーディング」で表示・非表示を切り替えられます（隠すときは生成し直さずに節を隠すだけ。
  付いていない解説を表示しているときは「スラッシュリーディングを付けて解説し直す」が出ます）
- **文法項目**: 英文を解説すると、解説の前に「どの文法項目が使われているか」がチップで並びます
  - チップを押すと本文の該当箇所がハイライトされ、項目の説明が出ます。「文法項目」タブでは、
    カテゴリ → 項目の一覧と、解説した英文での出現回数（よく出る順）を見られます

- **付箋**: ヘッダーの 📌 で「ここまで読んだ」を行に残せます。本文で選択していればその先頭の行、無ければ画面のいちばん上の行
  （章・節の見出しは飛ばします）に貼り、その行を下線と左の 📌 で示します。画面の幅で折り返しが変わっても同じ文字の行に付きます。
  次にその論文を開くと付箋の位置から表示します（Mac に保存するので、iPhone と Mac で共通）。
  📌 から「付箋へ移動」「ここに貼り直す」「付箋をはがす」ができ、「見た論文」には「📌 付箋あり」と出ます
- **選択のそばの操作メニュー**: 本文で語や文を選ぶと、すぐ下に「解説する・📌 付箋・コピー・🔊 発音」を出します。
  解説パネルまで移らずに操作できます（選択を解除すると閉じます）
- **目次と読んだ割合**: 本文の下端の線と右下の「☰ 目次 37%」で、どこまで読んだかが分かります。
  ボタンを押すと章・節の一覧が開き（今読んでいる節に印）、押した節へ移れます
- **コマンドパレット**: **⌘K**（Ctrl+K）で開き、打った文字で絞り込んで、↑↓ と Enter で実行します（Esc で閉じる。⚙ の設定からも開けます）。
  タブの切り替え、付箋、目次、配色、不具合の報告、節への移動、後で読む・見た論文を開く、arXiv の検索ができます。
  arXiv の URL・ID を貼ると、その論文を開く項目が先頭に出ます
- **引用の覗き見**: 本文の引用番号（`[14]` など）を押すと、読んでいる場所を動かさずに、その参考文献を番号の近くのカードに出します。
  arXiv ID が書かれていれば「この論文を開く」、題名を読み取れれば「arXiv で探す」（検索結果で概要を読めます）、
  「一覧の位置へ移る」で末尾の参考文献へ移れます。カードの外を押す・本文をスクロールする・Esc で閉じます
- **見た論文**: 開いた論文は「履歴」タブの「見た論文」に残り（最後に開いた順・開いた回数・調べた単語と英文の数）、そこから開けます。
  論文を開く前の「解説」タブにも最近の 5 本が出ます。「…」から一覧から外す（保存した本文と図も消すこともできる）
- **論文の保存**: 開いた論文の本文と図は Mac（SQLite）に保存され、2 回目からは arXiv にアクセスせずに表示します
- **論文を開く・探す**: 解説ペイン上部の欄に、arXiv の URL・ID（`1706.03762`、`arXiv:2301.12345v2` など）を入れると「開く」、
  それ以外の語を入れると「検索」になります。検索結果は「検索」タブに並び、「読む」かタイトルで開きます
  - 題名をそのまま入れると題名で探します（`attention is all you need`）。`"..."` で語句、`ti:` `au:` `abs:` `cat:` で欄を指定できます
  - 並び順は「関連度」と「新着」。「さらに表示」で続きを読み込みます
  - この欄はブラウザ標準の入力欄です。iPhone でも長押しでコピー・ペーストできます（本文の語句をコピーして、そのまま貼り付けて検索できます）
  - 論文を開いている間は、この欄を隠します（読むモード）。「検索」タブを開くと欄が出ます（検索モード）。
    PC では論文の題名の欄の「別の論文を開く」でも「検索」タブに切り替わり、欄に入力できます

- **後で読む**: 検索結果の「＋ 後で読む」で、論文を積んでおけます。「検索」タブの「後で読む」に、後から積んだものが上に並びます
  （論文を開く前の画面にも上から 3 件を出します）。開いても残るので、読み終えたら「外す」で消します。
  Mac に保存するので iPhone と Mac で共通です（版違いは 1 件にまとめ、上限は 200 件）
- **単語の辞書と AI 訳**: 単語を選ぶとローカル辞書（EJDict）で引きます。辞書に無い語（modalities など）は、
  ローカル LLM が文脈に合わせて訳し、「AI 訳」と明記して出します（誤りを含むことがあります）
  - **カタカナの読み**: 見出し語の横に、英語の発音をカタカナで出します（ローカル LLM の推定。「読みは AI 推定」と表示）。
    ⚙ の「単語の読みをカタカナで表示する」でオフにできます
  - **発音**: 見出し語の横の 🔊 で、端末の音声合成（Web Speech API, en-US）で読み上げます。
    ネットワークもサーバーも使わないのですぐ鳴ります（iPhone ではマナーモードだと鳴らないことがあります）
  - **品詞**: 訳を品詞（名詞・動詞・形容詞・副詞・前置詞・接続詞）ごとにまとめて表示します。EJDict には品詞の記号が無いため、
    訳語の形（〈C〉〈U〉、「…を〜する」、「〜な」など）と英語の語尾（-tion, -ous, -ly など）から推定しています（誤ることがあります）
  - 一度推定した読み・AI 訳は単語帳（SQLite）に保存し、次からは LLM を呼ばずにすぐ出します
- **直近の単語のメモ**: 論文の本文の上の 1 行（スマホでは画面のいちばん上）に、最近引いた 10 語を「英語＋短い訳」で新しい順に並べます。
  横にスワイプ（スクロール）すると前の語が見え、タップするとその語をもう一度引きます。
  思い出すための簡単なメモなので、サーバーやデータベースには送らず、ブラウザの localStorage にだけ保存します（⚙ で非表示・消去）
- **単語帳**: 「単語帳」タブに、引いた単語が検索回数・読み・訳と一緒に並びます（回数順・最近・ABC、前方一致で絞り込み）
  - 「＋ 単語を登録」で、辞書に無い語の訳や読みを自分で登録・編集できます（自分で登録した訳は AI 訳より優先）
  - チェックを付けて「選んだ N 語を削除」、または「検索回数の少ない語をまとめて削除」で整理します
  - 上限（`WORD_STORE_MAX`、既定 20,000 語）の 9 割を超えると、整理するか確かめる画面が出ます。
    上限を超えたら検索回数の少ない語（同じなら古い語）から自動で消します。自分で登録した語は自動では消しません
- **解説**: 「解説する」または **E** キー。**Esc** で選択を解除します（解説ペインにフォーカスがあっても使えます）
- **続けて質問する（チャット）**: 解説の下の「💬 続けて質問する」を押すと、その単語・英文と解説を踏まえて AI に何でも聞けます。
  質問欄は PC では解説パネルの下端、スマホでは会話の上に出ます（Enter か「送信」。生成中は「停止」）。よくある質問はボタンでも送れます
  - 会話は保存しません。別の単語・英文を選ぶか、解説を作り直すと消えます（会話があるあいだは E キーで作り直しません）
  - LLM のコンテキスト長に収めるため、長い会話では古いやり取りから忘れます
- **キャッシュ**: 一度解説した文は保存され、次からは LLM を呼ばずにすぐ表示されます（「キャッシュから表示」と出ます）。
  作り直すときは「再生成」を押します
- **履歴**: 「履歴」タブに、論文ごとに調べた単語と解説した文が新しい順に並びます。クリックで再表示（解説がキャッシュにあればそれも表示）、
  × で削除。「すべての論文」に切り替えると、ほかの論文の履歴と「論文を開く」ボタンが出ます
- **設定（⚙）**: 解説の設定、不具合・要望の送信、バージョンの表示をまとめた画面が開きます。
  PC は右上、スマホはいつも右下（下のタブの右端。選択中の小さな表示では 2 行目の右端）にあります。
  スマホでは開くとシートが「全体」になり、閉じると元の高さに戻ります。外側のタップ・✕・Esc で閉じます
- **配色**: 右上のボタンで 自動（OS の設定に従う）→ ライト → ダーク と切り替わります。論文ペインと解説ペインの両方に効き、ブラウザに保存されます。
  ダークでは図（黒い線の透過画像が多い）に白い下地を敷いて読めるようにしています
- **PC 用とスマホ用**: 画面幅 800px を境に、レイアウトが自動で切り替わります（設定は別々に保存）
  - **PC 用**（左右に並ぶ）: 境界線をドラッグで幅を変更（ダブルクリックで元に戻す、矢印キーでも調整可）
  - **スマホ用**（iPhone 15 などの縦画面）: 本文を画面いっぱいに出し、解説パネルは下から出るシートになります。
    つまみを上下にドラッグすると「少し・半分・全体」の 3 段階で止まり、タップで「少し ⇄ 半分」を切り替えます
    - 論文を開くと「少し」（本文を広く読む）、解説・検索・文字入力・フィードバックでは「全体」に自動で動きます
    - 本文で選んでいる間はシートを上げません（開いていれば「少し」に下げて、範囲を調整しやすくします。「自動で解説」がオンでも同じ）。
      英文を選ぶと、下げたシートに選んだ範囲の始めと終わりと「解説する」「開く」（解説を始めた後は「見る」）が出ます
    - **長押しで出るのはアプリの操作メニューだけ**です（端末標準の「コピー・調べる」のメニューは出ません）。
      長押しで単語を選び、指を離さずに動かすか、両端のつまみで単語ごとに範囲を広げます。数式は長押しで全体を選びます。
      選択の外をタップすると解除します。範囲を調整している間は操作メニューを隠し、指を離すと出ます。
      ⚙ の「長押しはアプリのメニューだけ出す」をオフにすると端末標準の選択に戻ります（この設定は指で操作する端末にだけ出ます。
      iPad にマウスやトラックパッドをつないで本文を選ぶときもオフにしてください）
    - 端末標準の選択を使うときは、操作メニューは範囲を調整している間は隠れ、選択が落ち着くと出ます
    - 単語を選んだときは「少し」のまま、シートの上に単語・読み・訳を小さく出します（本文を隠さない。このあいだは見出しは隠します）。「詳しく」かタップで「半分」に上げて辞書の全体と解説を出します
    - 選択中のテキストの欄に「解説する」ボタンが出ます。ボタンや文字はスマホでは大きめ、見出しは記号だけの省スペース表示です
    - ノッチ・ホームインジケーターを避けて表示し（safe area）、ダブルタップでの拡大は止めています。横に長い表は横スクロールします
    - Safari の共有メニューから「ホーム画面に追加」すると、ブラウザの枠なしで開けます
      （iOS 26 以降で上端の本文がぼやけないよう、ステータスバーの下は背景色の帯で覆い、本文はその下に隠れます）
